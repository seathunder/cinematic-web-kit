# Third-party material — read, do not ship

Everything below this folder was written by someone else.

## The boundary

**Nothing in here may be copied into `toolkit/`, `skill/`, or a client project.**

Use it for what it is good for:

- reading an approach before implementing your own
- comparing your solution against a working one
- citing prior art in `research/`
- confirming that a technique is viable before spending a day on it

That boundary is not bureaucratic caution. Two of the six repositories here have origins that could not
be confirmed, and sixteen of the seventeen skill packages carry no licence at all. Code whose
provenance you cannot state is code you cannot defend in a client engagement.

## Why these six repositories

They were the ones that actually downloaded. `specs/RESEARCH.md` surveys a much larger set — 34
repositories with verified URLs — but most were never fetched locally; a seventh folder
(`cinematic-scroll-skill`) arrived as zero files and was dropped from this bundle.

**So this folder is not the survey.** It is the subset that happens to be on disk. Read
`specs/RESEARCH.md` for the actual reference landscape, and `research/analysis/` for the teardowns of
what is here.
